# Duplicate File Finder

A lightweight Python web application built with Flask that scans a directory, identifies duplicate files using MD5 hashing, and provides a clean UI to view and manage them.

## Running the Project

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python main.py
   ```

3. Open your browser and navigate to `http://127.0.0.1:5000`.

## Running Tests

```bash
pytest
```
